# emergency-offline-ai

Emergency Offline AI (EOA) - Android offline disaster-prevention AI app (prototype)
現在は愛知県のデータに対応しています。将来は全国向けに広げる予定です。

【インストール方法】
1.このページの「EOA-v0.48.0.apk」をダウンロードします。
2.ダウンロードしたファイルを開きます。
3.インストールの確認が出たら「インストール」を押します。初めてのときは、使っているアプリ（ブラウザやファイル）に「不明なアプリのインストール」の許可が必要です。
4.一部の端末では、セキュリティ機能（Samsungの「自動ブロッカー」など）が止めることがあります。その場合は端末の設定で許可してください。
5.インストールできたらアプリを開きます。AIモデルはアプリの中からダウンロードできます。
おまけの「Invaders-v1.4.apk」も、同じ手順でインストールできます。
